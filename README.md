# AIホール 店舗ツール集

パチンコ店の仕事をAIで真似るシリーズ・店舗側編。架空店「AIホール」を題材にした、無料・登録不要のデモツール集です。

公開URL: https://ryoseiimai.github.io/pachinko-store-tools/

## ツール一覧

| ツール | ファイル | 内容 |
|---|---|---|
| ① 来店シミュレーター | `raiten.html` | 立地・商圏・曜日・イベントから今日の来客数と客層ペルソナを、公開統計に基づいて試算します。 |
| ② 経営シミュレーター | `keiei.html` | 台数×稼働率×粗利率で売上・利益・損益分岐点を試算します。シナリオ比較・感度分析つき。 |
| ④ 1日営業シミュレーター（3D） | `hall3d.html` | 台の配置を決めて1日（10:00〜23:00）を走らせ、台ごとのアウト・稼働・売上をヒートマップと3D店内表示で確認できます。一人称で店内を歩いたり、動画に書き出したりもできます。 |
| ③ パチつな（業界SNS） | 外部リンク | 店舗・メーカー・ライター・従業員が繋がる業界専用の掲示板SNS。求人・中古台・新台情報。 https://pachitsuna.kaeru3160.workers.dev/ |

## ローカル起動

外部依存やビルド手順は不要です。リポジトリ直下で簡易サーバーを立てて `index.html` を開くだけで動作します。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

`hall3d.html` はESモジュール（three.js）を利用しているため、`file://` ではなく必ずHTTPサーバー経由で開いてください。

## データ出典

来店・経営シミュレーターの試算パラメータは `data/industry_stats.json` にまとめた公開統計を参照しています。主な出典:

- レジャー白書2025（生産性本部）
- 日本遊技関連事業協会（日遊協）公表資料
- 全日本遊技事業協同組合連合会（全日遊連）資料
- P-WORLD、アミューズメントジャパン等の業界メディア報道

各項目には出典URLと年次を個別に付し、出典が確認できない項目は推定値と混在させず `null` としています。詳細は `data/industry_stats.json` の `meta.sources_used` を参照してください。

- 出玉・設定・還元率に関する情報は一切扱いません。
